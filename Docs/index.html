This repository's documentation defaults to English on the assumption that most readers are English speakers. A Korean translation of each page lives alongside it with a _kr suffix — see Docs/index_kr.html. The two tracks should stay in sync; when you edit one, check the other.

Diagrams are generated from the JSON specs in Docs/diagrams/ (English specs are unsuffixed, Korean specs are *.kr.<type>.json) using the archify skill. If the code changes and a diagram no longer matches, fix the spec and regenerate — hand-editing the HTML won't fix what's inside the diagram itself. The 0.90 → 0.91 migration guide has been removed; what was dropped and what to do instead is now in the "Removed Features" section of .claude/architecture.md (Korean).
