SuperSocketLite 2 문서

이 문서 묶음은 현재 코드 기준으로 TCP 연결, 수신 파이프라인, 송신 파이프라인, UDP 처리, 설정과 운영 포인트를 설명합니다. 최근 변경 사항인 ProcessReceiveResult, sequence receive filter, pooled UDP packet, Channel 기반 송신 큐를 반영했습니다. VS Code에서 통합 솔루션을 로드해 저장소 전체의 정의 이동과 코드 탐색을 활성화하는 방법도 제공합니다.

전체 아키텍처

 2

TCP 연결 흐름

서버 시작, accept loop, 세션 생성, receive pipe 시작, close 경로를 TCP 연결 관점에서 추적합니다.

SuperSocketLite_TCP_Connection_Flow.html
 3

수신 파이프라인과 ReceiveFilter

PipeReader, IReceiveFilter, ISequenceReceiveFilter, fixed-size/header 필터의 동작을 설명합니다.

SuperSocketLite_ReceivePipeline_ReceiveFilter.html
 4
